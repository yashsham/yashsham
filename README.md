<h2 align="center">🌟 Featured Architecture</h2>

🏗️ Cloud-Native Agentic Systems (2024-2025)

1. scaleMind MCP

Intelligent Autoscaling via Natural Language

Built on the Model Context Protocol (MCP) to allow natural language infrastructure management within Cursor IDE.

Integrates causal inference to predict scaling needs rather than relying on static thresholds.

Tech: Go, MCP, Kubernetes, AWS.

2. IaCGPT

Natural Language to Secure Infrastructure-as-Code

Transforms prompts into production-ready Terraform, K8s, and Docker configs using Gemini 2.0 Flash.

Solves the "cold start" problem for DevOps engineers with security-compliant scaffolding.

Tech: Vite, TypeScript, Gemini API.

🤖 Production-Grade Agentic Workflows

3. AI Judge Assistant (Legal RAG)

Precision Precedent Retrieval & Citation

Achieves ~92% relevance in case retrieval using vector similarity: $similarity = \cos(\theta) = \frac{A \cdot B}{\|A\|\|B\|}$.

Orchestrates multi-step reasoning via CrewAI to distinguish subtle legal nuances.

Result: Summarizes 50+ page legal documents in <30 seconds.

4. AI Data Scientist Crew

Autonomous Exploratory Data Analysis

A multi-agent system that cleans, analyzes, and visualizes datasets without human intervention.

Utilizes specialized agents for statistical modeling and automated PDF report generation.

Tech: CrewAI, Pandas, Matplotlib.

🌐 Cloud Infrastructure & Orchestration

5. CNCF Meshery & Meshify

Core maintainer of Meshery, managing service mesh complexity (Istio, Linkerd) using Go and TypeScript.

Developed Meshify, an analytical platform for monitoring microservice performance and security risks.

6. AutoRideEDA

Next-gen autonomous vehicle booking platform using Event-Driven Architecture (EDA).

Tech: Microservices, Apache Kafka, Neon PostgreSQL.
